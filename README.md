# Student Record and Marks Analyzer

A simple and efficient Python application designed to manage student profiles, input academic scores, calculate grades, and generate performance analysis summaries.

## 🚀 Features

* **Student Record Management:** Add and organize student details and IDs.
* **Marks Input & Processing:** Easily input subject-wise marks or test scores.
* **Automated Performance Analysis:** Calculate totals, percentages, averages, and assign letter grades automatically.
* **CLI-based Workflow:** Straightforward command-line interface for quick data processing.
